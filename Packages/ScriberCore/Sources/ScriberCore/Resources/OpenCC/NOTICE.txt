Scriber bundles dictionary data from Open Chinese Convert (OpenCC).

  Project:   https://github.com/BYVoid/OpenCC
  Version:   1.4.2 (dictionaries exported from the release's compiled .ocd2 files)
  Copyright: 2010-2026 Carbo Kuo and contributors
  License:   Apache License, Version 2.0 (full text in LICENSE-OpenCC.txt)

Files: CJK_Compatibility_Ideographs.txt, STCharacters.txt, STPhrases.txt,
STPhrases_GeneratedFromRegionalPhrases.txt, TWPhrases.txt, TWVariantsPhrases.txt,
TWVariants.txt (the s2twp.json chain), and TSCharacters.txt (used only to detect
characters that exist only in Traditional Chinese; not part of s2twp).

Modifications: the dictionaries were converted from OpenCC's binary .ocd2 format to
OpenCC's plain-text format, re-sorted by the UTF-8 bytes of each key, and given a
short header comment. Entries and values are unchanged.
STPhrases_GeneratedFromRegionalPhrases is generated by the OpenCC build
(data/scripts/generate_st_phrases_from_regional_phrases.py) and is not present as a
text file in the OpenCC source tree.

The conversion code that reads these files (ZhTW/OpenCC*.swift) is an independent
Swift reimplementation of OpenCC's s2twp.json configuration; it contains no OpenCC code.
