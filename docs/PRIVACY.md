# Scriber 隱私權政策

最後更新：2026 年 11 月 22 日

Scriber 是一個語音輸入工具，包含 iOS 鍵盤與 App，以及 macOS 選單列 App。這份文件說明 Scriber 怎麼處理你的資料。

## 重點

- Scriber **沒有自己的伺服器**。開發者不會收到、也無法存取你的錄音、你說的內容、你的 API key 或任何使用資料。
- Scriber **不做追蹤、不放廣告、不含任何分析或統計工具**。
- 你的錄音會**直接從你的裝置送到你自己選擇的語音辨識服務**，使用的是你自己的帳號和 API key。

## Scriber 會處理哪些資料

### 你的聲音
只有在你按下麥克風（iOS）或快捷鍵（macOS）之後，到你結束之前，Scriber 才會錄音。錄下的音訊會送到你在設定裡選擇的服務進行辨識：

- ElevenLabs（Scribe）
- Groq（Whisper）
- 或你自己設定的其他相容服務

錄音在辨識完成後就會從裝置上刪除。只有在網路失敗、需要重試時，才會暫時保留到重試成功或你取消為止。

### 辨識出的文字
如果你開啟「AI 潤飾」、使用翻譯或「說話改字」，辨識出的文字（以及「說話改字」時你選取的文字）會送到你選擇的 AI 服務處理：

- Groq
- Anthropic（Claude）

沒有開啟這些功能時，文字整理完全在你的裝置上進行。

### 歷史紀錄、個人字典、使用統計
這些只存在你的裝置上，不會上傳。你可以在設定裡關閉歷史紀錄，或隨時清除。

### API key
存放在裝置的鑰匙圈（Keychain）裡，只用來連線到對應的服務，不會傳送到其他地方。

### 診斷紀錄
App 內的診斷紀錄只記錄事件和狀態（例如「開始錄音」「辨識完成，耗時多少」），**不包含你說的內容、輸入的文字或 API key**。它只存在你的裝置上，除非你自己複製並傳給別人。

## 第三方服務

你的音訊和文字由你選擇的服務商處理，適用他們各自的隱私權政策和資料保留規則。使用前請自行查閱：

- ElevenLabs：https://elevenlabs.io/privacy
- Groq：https://groq.com/privacy-policy
- Anthropic：https://www.anthropic.com/legal/privacy

Scriber 使用的是你自己向這些服務商申請的帳號，開發者與這些服務商之間沒有資料分享關係。

## 權限

### iOS
- **麥克風**：錄下你說的話。
- **鍵盤的「允許完整取用」**：讓鍵盤可以和 Scriber App 溝通（麥克風在 App 裡，鍵盤本身不能錄音），以及連上網路。Scriber 鍵盤沒有打字按鍵，不會記錄或傳送你在其他鍵盤輸入的內容。

### macOS
- **麥克風**：錄下你說的話。
- **輔助使用**（選用）：偵測快捷鍵，以及把辨識結果貼到游標位置。Scriber 只判斷你按的是不是觸發鍵，不會記錄你的按鍵內容。不授權也能使用，只是要自己按貼上。

## 兒童

Scriber 不是針對兒童設計的產品，也不會刻意收集任何人的個人資料。

政策有變更時會更新這份文件和上方的日期。
